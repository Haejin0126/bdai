# Streamlit Executive BI Dashboard 제작 최종 프롬프트

## 0. 프로젝트 미션

당신은 이커머스 기업의 시니어 BI 개발자이자 데이터 시각화 및 UI/UX 디자인 전문가입니다.

제공된 스마트폰 카테고리 고객 행동 데이터 D1~D8을 사용해 마케팅 총괄 임원(CMO)을 위한 Streamlit 기반 BI 대시보드를 제작하세요.

이 대시보드는 이미 제작된 PowerPoint 경영 분석 보고서와 하나의 디자인 시스템을 공유해야 합니다.

**절대 변경하면 안 되는 것:**

- D1~D8의 원본 데이터 값
- 데이터의 분석 기간과 분모
- RFM 세그먼트 정의
- 시즌별 핵심 전략과 우선순위
- 기존 3개 페이지 구성 및 기능
- 제공된 수치의 정밀도
- 누락값을 임의로 생성하지 않는 원칙

새로 개선할 항목은 색상 체계, 레이아웃, 시각적 강조, 대시보드의 가독성과 디자인 완성도입니다.

# 1. 프로젝트 개요

## 분석 대상

- 카테고리: 스마트폰
- 기간: 2019-10~2020-04
- 성수기: 2019-10~2019-11
- 비수기: 2019-12~2020-04
- 퍼널 판정 단위: 사용자-월
- RFM 판정: 시즌별 5분위 스코어링
- 독자: CMO

## 핵심 비즈니스 질문

**"시즌별로 어느 고객 세그먼트에 마케팅 자원을 먼저 투입해야 하는가?"**

## 핵심 메시지

성수기에는 챔피언·충성 고객 유지에 집중합니다.

비수기에는 신규 고객 재구매 유도와 휴면 고객 리마인드를 우선합니다.

이탈 위험 고객은 시즌 공통 재활성화 검토 대상으로 분류하되, 특히 비수기 소표본에 유의합니다.

# 2. 개발 환경

프로젝트 구조:

```text
/
├── app.py
├── data.py
├── requirements.txt
└── .streamlit/
    └── config.toml
```

필수 기술:

- Streamlit
- Plotly
- pandas

추가 패키지 없이 실행되어야 합니다.

모든 수치는 `data.py`에 저장하고, `app.py`는 데이터 구조를 읽어 화면을 렌더링합니다.

로컬 실행:

`streamlit run app.py`

배포 대상:

Streamlit Community Cloud 무료 환경.

# 3. PPT와 통일된 디자인 시스템

## 3.1 디자인 방향

디자인 키워드:

**Executive / Minimal / Premium / Data-driven / Indigo & Lavender**

스타일은 첨부된 PPT의 다음 요소를 계승합니다.

- 인디고 블루 결론 배너
- 블랙에 가까운 인사이트 패널
- 연한 쿨그레이 차트 배경
- 바이올렛 계열 차트
- 크고 명확한 주요 수치
- 굵은 한 줄 결론
- 넉넉한 여백
- 장식보다 메시지를 강조하는 구성

Streamlit 기본 화면을 그대로 사용하는 느낌이 아니라, 기업의 브랜드 디자인 시스템이 적용된 전문 BI 서비스처럼 구현하세요.

단, 인디고를 과도하게 사용해 눈이 피로해지지 않도록 합니다.

## 3.2 PPT에서 추출한 실제 색상

다음 색상은 제공된 PowerPoint 슬라이드 PNG에서 추출한 대표 픽셀값입니다.

| 이름 | HEX | 사용 목적 |
|---|---|---|
| Primary Indigo | #1501A5 | 결론 배너, 핵심 KPI, 주요 선택 |
| Royal Violet | #584CCE | 보조 강조, 선택된 차트 요소 |
| Soft Lavender | #B7AEF9 | 보조 데이터, 연한 그래프 |
| Periwinkle | #A4B3F9 | 비수기, 비교 막대 |
| Muted Violet | #7C7AA4 | 중립 비교, 보조 텍스트 |
| Light Gray | #D8D9E1 | 비선택 요소, 비활성 막대 |
| Canvas Gray | #F3F5F8 | 보조 카드, 그래프 영역 |
| Charcoal | #0E0D12 | 인사이트 패널, 제목 |
| White | #FFFFFF | 전체 화면 및 주요 카드 |
| Text Gray | #474747 | 설명, 보조 본문 |

이 색상들을 `COLORS` 딕셔너리로 정의하여 앱 전체에서 재사용하세요.

색상 값을 차트마다 별도로 하드코딩하지 마세요.

## 3.3 색상 역할 정의

### 전체 화면

- 전체 배경: `#FFFFFF`
- 주요 카드: `#FFFFFF`
- 보조 카드: `#F3F5F8`
- 기본 제목: `#0E0D12`
- 보조 텍스트: `#474747`
- 얇은 테두리: `#D8D9E1`

### 시즌 구분

- 성수기: `#1501A5`
- 비수기: `#A4B3F9`
- 비수기 강조 텍스트: `#584CCE`

비수기 막대 위에 직접 글자를 넣는 경우 어두운 글자를 사용합니다.

시즌 비교에서는 성수기와 비수기 색을 절대 바꾸지 않습니다.

시즌 선택에 따라 선택된 시즌은 원래 색상과 강한 테두리를 유지하고 다른 시즌은 투명도 0.25~0.35 수준으로 연하게 처리합니다.

비선택 값은 숨기지 않습니다.

### 변화(%p) 차트

- 양수: `#1501A5`
- 음수: `#7C7AA4`
- 0 기준선: `#474747`

원본 PPT에 없는 빨간색은 기본적으로 사용하지 않습니다.

대신 양수·음수는 색상뿐 아니라 `+`, `−` 부호와 범례로 구분합니다.

양수와 음수의 시각적 차이가 충분하지 않은 경우 음수에 패턴 또는 테두리 스타일 차이를 추가합니다.

### 세그먼트 차트

PPT의 6개 세그먼트를 다음 색상으로 구분합니다.

- 챔피언: `#1501A5`
- 충성 고객: `#584CCE`
- 신규 고객: `#7C7AA4`
- 이탈 위험: `#A4B3F9`
- 휴면: `#B7AEF9`
- 관심 필요: `#9588D8`

같은 세그먼트는 페이지 간 동일한 색을 유지합니다.

단, 시즌이 범례인 차트에서는 세그먼트 색보다 시즌 색을 우선합니다.

차트마다 데이터 구분 기준이 시즌인지 세그먼트인지 명확히 하여 범례 혼동을 방지하세요.

## 3.4 색상 사용 비중

전체 화면을 기준으로 권장 비중:

- 화이트·라이트그레이: 약 80%
- 바이올렛 및 라벤더: 약 15%
- 딥 인디고·차콜 강한 강조: 약 5%

이는 엄격한 픽셀 비율이 아니라 시각적 균형을 위한 디자인 원칙입니다.

짙은 색상은 중요한 결론과 선택 상태에만 집중적으로 배치합니다.

## 3.5 페이지 공통 레이아웃

페이지 상단:

1. 작은 인디고 섹션 라벨
2. 큰 차콜 페이지 제목
3. 한 줄 핵심 메시지
4. 우측 필터 및 기준 배지

PPT의 결론 배너와 유사한 요소가 필요한 경우:

- 배경 `#1501A5`
- 글자 `#FFFFFF`
- 왼쪽에 흰색 결론 배지
- border-radius 12~16px
- 내부 여백 24~32px

Insight 패널:

- 배경 `#0E0D12`
- 제목 `#B7AEF9`
- 본문 `#FFFFFF`
- 핵심 수치는 굵게
- 페이지당 최대 1개

카드:

- 모서리 12~14px
- 1px 연회색 테두리
- 큰 그림자 금지
- 충분한 내부 여백
- KPI 수치가 가장 먼저 보이도록 구성

기본 본문은 밝은 배경 위의 어두운 글자를 사용하세요.

## 3.6 글꼴

Noto Sans KR 적용.

CSS `@import` 사용.

권장 글자 크기:

- 페이지 제목: 28~32px
- 핵심 메시지: 18~22px
- KPI 숫자: 28~36px
- 차트 제목: 16~19px
- 본문: 14~16px
- 각주: 12~13px

숫자는 가능하면 tabular numerals로 표시합니다.

## 3.7 인터랙션 디자인

선택된 탭·버튼·필터:

- 흰색 또는 밝은 배경
- 굵은 인디고 테두리
- 인디고 또는 어두운 글자
- 분명한 선택 상태

비선택 상태:

- 라이트그레이 배경
- 중립색 글자

버튼 최소 높이 44px.

키보드 조작이 가능한 Streamlit 기본 위젯을 우선합니다.

Streamlit 내부 자동 생성 클래스에 과도하게 의존하는 CSS는 피하세요.

# 4. 공통 기능 및 데이터 규칙

## 4.1 탭 구성

`st.set_page_config(layout="wide")`

`st.tabs`로 다음 세 페이지를 구성합니다.

1. 시즌별 고객 행동
2. RFM 세그먼트 분석
3. 시즌 × 세그먼트 우선순위 → 실행전략

전역 시즌 필터는 두지 않습니다. 시즌 선택이 필요한 차트는 각각 독립적인 `st.session_state` key를 가진 로컬 컨트롤을 사용합니다.

두 시즌 비교가 목적이면 기본적으로 두 시즌을 함께 표시하며, 선택 시즌은 매트릭스 열 강조와 같이 비교 정보를 유지하는 데에만 사용합니다.

## 4.2 숫자 서식

- 인원: `322,110명`
- 비율: `54.5%`
- 비율 차이: `+7.4%p`
- 금액: `$1,617`
- 결측값: `—`
- 해당 없음: `해당 없음`

원본 소수점은 계산에 보존합니다.

값은 data.py 원본에서 읽어 오며 수치가 없는 경우 추정하지 않습니다.

## 4.3 Plotly 공통 설정

`st.plotly_chart`를 사용하세요.

차트마다:

- 제목은 지표명이 아닌 메시지 문장
- 부제에는 단위, 기간, 판정 단위 명시
- 막대와 점에 값 라벨 상시 표시
- 범례 제공
- 툴팁에 값, 분모, 기간 표시
- 그리드라인은 연한 회색
- 과도한 그래프 외곽선 제거
- 0 기준선, 점선, 음영 등은 Plotly 옵션으로 구현

파이 차트, 3D, 그라데이션은 금지합니다.

라벨 대비가 부족한 경우 자동으로 어두운 텍스트를 적용하세요.

# 5. 페이지 1 — 시즌별 고객 행동

## 헤드라인

"장바구니 고객의 구매 전환율은 성수기 54.5%, 비수기 47.1%입니다. 가장 큰 이탈은 조회→장바구니 단계에서 발생합니다."

## 상단 KPI 6종

D1 데이터를 사용합니다.

- 방문자당 매출(NSM)
- 구매 전환율
- 구매자당 매출
- 30일 내 재구매 고객 수
- 조회→장바구니 전환율
- 장바구니→구매 전환율

가로 6개 카드로 배치합니다.

각 카드에는 성수기, 비수기, 격차를 표시합니다.

카드 배경은 흰색 또는 라이트그레이로 하고, 성수기 값은 인디고, 비수기 값은 Royal Violet로 표시합니다.

두 시즌의 값이 모두 없으면 격차도 `—`로 처리합니다.

## 차트 1. 시즌별 장바구니→구매 전환율

왼쪽 약 40%.

막대 / 표 전환 토글.

기본값은 막대.

- 성수기 54.5%
- 비수기 47.1%
- 차이 +7.4%p

성수기는 딥 인디고 막대, 비수기는 페리윙클 막대를 사용합니다.

차이를 표시하는 화살표는 인디고 실선 또는 점선으로 표현합니다.

표 모드에서는 D2의 퍼널 데이터를 표시합니다.

제목:

"성수기 장바구니→구매 전환율이 비수기보다 7.4%p 높습니다."

## 차트 2. 월별 장바구니→구매 전환율

오른쪽 약 60%.

- x축: 2019-10~2020-04
- y축: 0~70%
- 회색 연결선
- 성수기 월: 인디고 점
- 비수기 월: 페리윙클 점
- 성수기 구간: 연한 라벤더 음영
- 시즌 평균 54.5%, 47.1%: 점선
- x축 라벨 아래 장바구니 도달 인원 표시

제목:

"성수기 우위는 10월이 이끌고, 11월은 12월과 비슷한 수준입니다."

## 차트 3. 퍼널 단계별 전환율

전체 폭 묶음 막대.

그룹:

- 조회→장바구니
- 장바구니→구매

각 그룹에 성수기/비수기 두 막대를 배치합니다.

시즌별 색상은 전체 대시보드의 시즌 색과 동일하게 유지합니다.

제목:

"조회→장바구니 단계의 전환율이 특히 낮으며, 비수기는 3.0%입니다."

D2 사용.

## 차트 4. 월별 조회·장바구니·구매 인원

좌측 배치.

- 월별 3개 가로 막대
- 조회, 장바구니, 구매
- 기본 선형 축
- 로그 축 토글
- 값 라벨 표시
- 2019-12 이후 연한 회색 음영
- '수집 영향 가능성' 주석

이 차트는 단계 비교이므로 시즌 색이 아닌 차콜, 로열 바이올렛, 라벤더의 서로 구분되는 색을 사용합니다.

D3 사용.

## 차트 5. 시즌별 구매 횟수 퍼널

우측 배치.

단계:

첫 구매 → 2회 이상 → 3회 이상 → 4회 이상

- 툴팁에 단계 도달 인원 및 직전 단계 전환율

부제:

# 6. 페이지 2 — RFM 세그먼트 분석

## 페이지 헤드라인

"성수기 매출 1위는 충성 고객, 비수기는 휴면 고객입니다. 이탈 위험 고객의 구매자당 매출은 비수기에 충성 고객보다 높습니다."

## RFM 정의 스트립

5분위 기준:

- 챔피언: R≥5, F≥5, M≥5
- 충성: F≥4, R≥3
- 신규: R≥4, 구매 1회
- 이탈 위험: R≤2, F≥3
- 휴면: R≤2
- 관심 필요: 나머지

위 순서로 적용합니다.

원시 고객별 점수가 없으므로 세그먼트를 재산출하지 않습니다.

## KPI 4종

D6 사용.

- 분석 고객 수
- 단골 고객 비중
- 매출 1위 세그먼트와 비중
- 이탈 위험 구매자당 매출

성수기와 비수기 값을 모두 제공합니다.

## 차트 1. 고객 비중 vs 매출 비중

왼쪽.

가로 묶음 막대.

고객 비중: Cool Gray.

매출 비중: 선택 시즌 색상.

매출 1위 세그먼트에는 인디고 테두리와 '매출 1위' 배지를 표시합니다.

제목:

"성수기엔 단골이 매출의 52.3%, 비수기엔 신규·휴면·관심 필요가 69.9%를 차지합니다."

D5 사용.

## 차트 2. 매출 비중 변화(%p)

오른쪽.

계산:

비수기 매출 비중 − 성수기 매출 비중.

양방향 가로 막대.

- 양수: Primary Indigo
- 음수: Muted Violet
- 0 기준선: Charcoal
- 모든 값에 +/− 부호
- 변화 절댓값 기준 정렬
- 시즌 토글과 무관하게 두 시즌 차이를 표시

D5 사용.

## 차트 3. 이탈 위험 vs 충성 고객 구매자당 매출

전체 폭 또는 넓은 카드에 묶음 세로 막대를 배치합니다.

x축: 성수기 / 비수기.

각 그룹:

- 이탈 위험: Primary Indigo
- 충성 고객: Muted Violet 또는 Light Gray

구매자당 매출을 원본 D5에서 읽습니다.

각 시즌별 충성 고객을 100으로 놓았을 때의 이탈 위험 상대 차이도 계산해 주석으로 표시합니다.

제목:

"이탈 위험 고객의 구매자당 매출은 비수기에 충성 고객보다 높습니다."

부제:

"관측 기간 내 누적 · 구매 고객 기준"

D5 사용.

## 차트 4. RFM 요약표

행:

챔피언, 충성 고객, 신규 고객, 이탈 위험, 휴면, 관심 필요.

시즌별 열:

- 고객 수
- 고객 비중
- 매출 비중
- 구매자당 매출
- 이전 구매 경험 비율

두 시즌 모두 항상 표시합니다.

성수기의 이전 구매 경험 비율은 '해당 없음'으로 표시합니다.

정렬 가능한 표를 구성합니다.

선택한 세그먼트는 연한 라벤더 배경과 인디고 왼쪽 테두리로 강조합니다.

## 별도 Insight 패널

PPT와 같은 Charcoal 배경의 인사이트 카드에 다음 내용을 표시합니다.

- 성수기 매출 1위: 충성 고객 31.7%
- 비수기 매출 1위: 휴면 33.8%
- 이탈 위험의 상대 구매자당 매출: D5에서 계산
- 전략적 시사점: 시즌별로 공략 고객을 달리해야 함

하드코딩하지 않고 D5와 D6에서 읽어 표시합니다.

D8 각주 표시.

# 7. 페이지 3 — 시즌 × 세그먼트 우선순위 → 실행전략

## 최상단 결론 배너

PPT와 동일한 인디고 `#1501A5` 배경으로 구현합니다.

결론:

"성수기에는 단골 유지에, 비수기에는 재구매 유도와 휴면 리마인드에 자원을 우선 투입합니다."

왼쪽에 흰색 바탕의 '결론' 캡슐형 배지를 표시합니다.

텍스트는 흰색, 보조 설명은 라벤더로 표현합니다.

## 구성 1. 우선순위 매트릭스

6개 세그먼트 × 2개 시즌.

각 셀:

- 우선순위: ● 또는 ○
- 핵심 액션 한 줄

강조 규칙:

- 최우선: 인디고 점과 연한 라벤더 배경
- 보조: 중립 회색 점
- 이탈 위험: 별도 '공통 재활성화 검토' 배지

시즌 토글을 선택하면 해당 시즌 열의 배경과 테두리를 강조합니다.

D7 사용.

## 구성 2. 세그먼트 액션 카드

6개의 Streamlit 버튼.

- 챔피언
- 충성 고객
- 신규 고객
- 이탈 위험
- 휴면
- 관심 필요

선택하면 `st.dialog`로 모달을 엽니다.

모달 구성:

- 상단: 인디고 헤더
- 세그먼트명
- 성수기 대상 인원
- 비수기 대상 인원
- 각 시즌별 핵심 액션
- 움직일 지표
- 근거 페이지 및 D번호
- '초안·팀 확정 필요' 안내

모달은 기본 X, ESC, 바깥 클릭으로 닫습니다.

D5, D7 사용.

## 구성 3. 비교용 기회 규모

가로 막대 차트.

계산:

고객 수 × 구매자당 매출.

시즌 토글에 반응합니다.

막대는 선택 시즌 색상으로 표시합니다.

선택 세그먼트는 진한 테두리로 강조합니다.

값 라벨 및 툴팁:

- 세그먼트
- 고객 수
- 구매자당 매출
- 산식
- 계산 결과

정렬: 계산값 내림차순.

반드시 아래 설명을 표시합니다.

"구매자당 매출은 구매 고객 기준이므로 이 계산값은 실제 총매출이나 미래 예상 매출이 아닌 비교용 규모 지표입니다. 비용, 채널, 반응률 데이터가 없어 ROI를 뜻하지 않습니다."

D5 사용.

## 구성 4. 시즌별 전략 요약

D7의 전략 요약 데이터를 표로 표시합니다.

열:

- 시즌
- 우선 세그먼트
- 핵심 전략
- 움직일 지표

테이블 아래에 Charcoal 인사이트 패널을 배치합니다.

공통 시사점:

"두 시즌 모두 구매자당 매출이 높은 이탈 위험 고객은 관심 행동이 확인된 고객부터 소규모 재활성화를 시험합니다."

D7 사용.

## D7. 시즌별 우선순위·핵심 액션

D7은 팀 확정이 필요한 전략 초안입니다.

### 챔피언

- 성수기: ● 최우선
- 성수기 액션: VIP 선예약권, 전용 사은품 패키지
- 비수기: ○ 보조
- 비수기 액션: 프리미엄 선공개, 번들·업셀로 씀씀이 유지
- 움직일 지표: 재구매 고객 수

### 충성 고객

- 성수기: ● 최우선
- 성수기 액션: 연계 기기·액세서리 패키지, 금액 구간 적립
- 비수기: ○ 보조
- 비수기 액션: 추천인 프로그램, 재구매 유도로 고객 수 이탈 방지
- 움직일 지표: 재구매 고객 수

### 신규 고객

- 성수기: ○ 보조
- 성수기 액션: 웰컴 쿠폰, 저비용 채널 온보딩
- 비수기: ● 최우선
- 비수기 액션: 첫 구매 후 액세서리 쿠폰으로 두 번째 구매 유도
- 움직일 지표: 첫 구매→재구매 전환율

### 이탈 위험

- 성수기: ● 최우선(공통)
- 성수기 액션: 관심 행동이 확인된 고객부터 소규모 재활성화 파일럿
- 비수기: ● 최우선(공통)
- 비수기 액션: 최소 구매금액·할인 한도를 둔 윈백 쿠폰
- 움직일 지표: 재구매 고객 수

### 휴면

- 성수기: ○ 보조
- 성수기 액션: 신제품 소식 중심 저비용 푸시
- 비수기: ● 최우선
- 비수기 액션: 저비용 리마인드, 세트 구매 혜택으로 객단가 상승 유도
- 움직일 지표: 전체 고객 수

### 관심 필요

- 성수기: ○ 보조
- 성수기 액션: 자동화 프로모션 노출
- 비수기: ○ 보조
- 비수기 액션: A/B 테스트로 두 번째 구매 유도 메시지 탐색
- 움직일 지표: 전환율, 재구매 고객 수

### 시즌별 전략 요약

| 시즌 | 우선 세그먼트 | 핵심 전략 | 움직일 지표 |
|---|---|---|---|
| 성수기 | 챔피언, 충성 고객 | 단골 유지와 구매자당 매출 확대 | 재구매 고객 수, 구매자당 매출 |
| 비수기 | 신규, 휴면 고객 | 재구매 유도, 휴면 리마인드, 장바구니 리마인드(보조) | 첫 구매→재구매 전환율, 전체 고객 수 |

공통 시사점:

두 시즌 모두 구매자당 매출이 높은 이탈 위험 고객은 관심 행동이 확인된 고객부터 소규모 재활성화를 시험합니다.

## D8. 모든 페이지 하단 각주

다음 사항을 매 페이지 하단에 표시합니다.

- 장바구니 없이 구매한 사용자는 퍼널에서 제외합니다.
- 같은 달 안의 이벤트만 인정합니다.
- 시즌 값은 월별 도달 인원의 합산입니다.
- 12월 이후 이벤트 급감은 데이터 수집 영향 가능성이 있으므로 비수기 값을 경향으로 해석합니다.
- 세그먼트는 시즌별 RFM 5분위와 기준일로 나누므로 시즌 간 직접 비교에 한계가 있습니다.
- 신규는 시즌 내 첫 구매 기준입니다.
- 비수기 신규 고객의 17.7%는 이전 시즌 구매 경험이 있습니다.
- 비수기 이탈 위험 143명은 소표본으로 참고용입니다.
- 수량, 비용, 채널 데이터는 제공되지 않았습니다.

RFM 기준일:

- 성수기: 2019-11-30
- 비수기: 2020-04-30

# 9. 정밀 계산 및 필터 규칙

## 계산 가능한 값

입력값에서 계산하세요.

- 시즌 간 %p 차이
- 월 범위별 합산 전환율
- 단계별 이탈 인원과 이탈률 검증
- 첫 구매 대비 잔존 비율
- 세그먼트별 매출 비중 변화
- 챔피언+충성 고객 비중
- 이탈 위험 대비 충성 고객 구매자당 매출 상대 차이
- 고객 수 × 구매자당 매출

두 시즌 값 중 하나라도 없으면 격차를 계산하지 말고 `—`로 표시합니다.

0으로 나누는 경우에도 `—`로 처리합니다.

## 필터 반응 범위

페이지 1:

- 월별 도달 인원과 월별 장바구니→구매 전환율은 각각 독립적인 다중 월 선택 상태를 사용
- 각 월별 차트의 초기화는 해당 차트의 선택만 초기화
- 월별 도달 인원, 퍼널 근거, 구매 횟수 퍼널의 시즌 강조 상태는 서로 독립

페이지 2:

- 리본 차트, 포지셔닝 맵, 시즌별 요약표는 서로 독립적인 시즌 상태를 사용
- 변화(%p) 차트는 두 시즌의 차이이므로 시즌 토글과 무관
- 이탈 위험 vs 충성 비교는 두 시즌 모두 표시
- 세그먼트 선택은 선택 행 강조에 사용

페이지 3:

- 우선순위 매트릭스와 기회 규모 차트는 각각 독립적인 시즌 상태를 사용
- 매트릭스 시즌 선택은 성수기·비수기 두 열을 유지하면서 해당 열만 강조
- 세그먼트 선택은 강조에 사용
- 액션 카드 모달은 별도 버튼으로 열림

필터 상태 관리 시 `st.session_state` key 충돌을 방지하세요.

## 데이터 검증

D3 시즌별 월 도달 인원 합계와 D2 시즌별 퍼널 인원을 검증합니다.

D5 세그먼트 고객 수 합계와 시즌 분석 고객 수를 검증합니다.

반올림 비율에는 적절한 허용 오차를 적용합니다.

원본 비율이 반올림된 상태라면 계산값으로 원본을 덮어쓰지 않습니다.

성수기 D5 매출 비중의 '검산 필요' 주석을 유지합니다.
